# Original modeling references

The supplied SVG and PNG diagrams are the original references shown in Lecture 2. They are dedicated to the public domain under CC0 1.0; see reference/LICENSE.txt.

The images are ready to use. To recreate the editable diagrams, run `python build_reference.py` with Python 3. To recreate their PNG versions, install Node.js and run `npm install sharp`, then `node render_reference.cjs`. The output is written to the adjacent `reference` folder.

The front image is an orthographic alignment guide. The side section explains the cavity and back wall. The three-quarter drawing explains depth and is not an orthographic alignment guide.
